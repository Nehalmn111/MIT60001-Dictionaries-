# Python Dictionaries Practice

This repository contains exercises and examples I completed while learning and revising Python dictionaries through MIT's **6.0001: Introduction to Computer Science and Programming in Python** course.

Working through these exercises helped me understand how dictionaries store data, how to work with keys and values, how to iterate through dictionaries, and how to use them inside functions.
